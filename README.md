# 水位をめくる — sea level, page by page

海面が上がると、土地がどこから水に浸かっていくのかを、薄い紙を1丁ずつめくって見る習作です。場所は徳島（吉野川の河口）と仙台（名取川の河口と仙台空港）から選べます。めくれる高さは場所ごとに決めていて、徳島は+2mまで、仙台は+1.75mまでです（仙台は+2mで1枚のうちに倍以上へ広がるため）。

公開ページ: https://structure-and-representation.github.io/sea-level-page-by-page/

## 読み方

- 藍で染めたところが水、白く残っているのが土地です。
- 最初の面が現状です。紙を右へ1丁めくるごとに、海面が0.25m上がります（+2.0mまで）。
- 染めは重なるほど濃くなります。右のページでは、早くから水に浸かっている場所ほど濃い藍になります。
- 左の未読の束は、白く曇って見えます。めくって右に置くと澄みます。

## 操作

- 紙を右へドラッグ（スワイプ）するとめくれ、左へで戻ります。下の目盛りと左右の矢印キーでも動きます。
- 「真上から見る」で、真上からの視点に切り替わります。
- 視点は、マウスの右ドラッグか2本指でも回せます。

## 注意

- その高さの水が、海や川から地続きで届く土地だけを水にしています。
- 堤防の高さは標高データに含まれる範囲で反映していますが、水門は閉まらない前提です。薄い防潮壁は拾えていない可能性があります。
- 決壊や排水は扱っていません。将来の予測ではありません。

## データ

- 標高: 国土地理院 [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（標高タイル・基盤地図情報数値標高モデル 5mメッシュ）を加工して作成。高さの基準は東京湾平均海面。約16mの格子に平均して簡略化し、山側の測量の欠けは周りの高さで埋めています。
- 地名の位置: 国土地理院の地名検索で調べた代表点。
